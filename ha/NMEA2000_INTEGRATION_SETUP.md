# Настройка интеграции NMEA 2000 в Home Assistant (pgn_include & Предотвращение замусоривания)

## 📋 Обзор и проблема замусоривания

Интеграция `nmea2000` в Home Assistant принимает сырой поток NMEA 2000 сообщений с TCP-шлюза (порт `4001`). По умолчанию, если список разрешённых PGN не задан или расширен без ограничений, интеграция **создаёт устройство и набор сущностей (`sensor.*`) для каждого PGN и каждого уникального устройства/MMSI**, увиденного на шине.

При приёме сообщений от проходящих судов по AIS (PGN 129038, 129039 и др.) это приводит к тому, что файлы `.storage/core.device_registry` и `.storage/core.entity_registry` в Home Assistant непрерывно замусориваются сотнями временных записей проходящих судов.

### Решение:
1. **Белый список PGN (`pgn_include`)**: Явное указание только тех PGN, которые действительно необходимы для работы приборов лодки и дашбордов (`ha/sailing-dash` и `ha/ais`).
2. **Использование кастомного компонента `ais_targets`**: Для AIS-целей используется специальный компонент, создающий динамические объекты `geo_location.ais_<mmsi>` в оперативной памяти с автоматическим удалением по таймауту, вместо создания постоянных `sensor.*` устройств в базе и реестре HA.
3. **Регулярная зачистка реестра**: Запуск скрипта очистки при необходимости удаления устаревших дубликатов устройств.

## 🛠️ Категории необходимых PGN

Ниже приведён полный перечень PGN, используемых в проекте, разбитый по категориям:

### 1. Системные и служебные PGN (ISO / Device Discovery)
Необходимы для работы самой интеграции `nmea2000`, определения приборов на шине и построения карты сети:
* **`60928`** — ISO Address Claim (определение устройств на шине, ISO Name, unique_number)
* **`126996`** — Product Information (модель устройства, серийный номер, версия прошивки)
* **`126464`** — PGN List (список передаваемых/принимаемых PGN)
* **`59904`** — ISO Request (запрос системной информации)

### 2. Навигация и приборы лодки (`ha/sailing-dash`)
Необходимы для работы виртуальных сенсоров `sensor.boat_*` и графиков парусного дашборда:
* **`128259`** — Speed, Water Referenced (скорость относительно воды / STW)
* **`128267`** — Water Depth (глубина под эхолотом/килем)
* **`129025`** — Position, Rapid Update (быстрый GPS: широта и долгота)
* **`129026`** — COG & SOG, Rapid Update (курс COG и скорость SOG относительно грунта)
* **`129029`** — GNSS Position Data (полные GPS данные)
* **`127250`** — Vessel Heading (компасный курс судна HDG)
* **`127258`** — Magnetic Variation (магнитное склонение)
* **`130306`** — Wind Data (скорость и угол ветра, референс)
* **`130310`** — Environmental Parameters (атмосферное давление, температура воздуха)
* **`130312`** — Temperature (температура воды / воздуха / CPU)

### 3. Судовые системы, баки и двигатель
Используются для мониторинга танков (включая Gobius C), батарей и двигателя:
* **`127505`** — Fluid Level (уровни в танках — топливо, вода, серая вода)
* **`127508`** — Battery Status (напряжение и ток аккумуляторов)
* **`127506`** — DC Detailed Status (состояние системы постоянного тока)
* **`127488`** — Engine Parameters, Rapid Update (обороты двигателя)
* **`127489`** — Engine Parameters, Dynamic (давление и температура двигателя)

### 4. Сообщения AIS (`ha/ais`)
Используются для карты и списка целей AIS в `ha/ais`:
* **`129038`** — AIS Class A Position Report (позиция судов класса A)
* **`129039`** — AIS Class B Position Report (позиция судов класса B)
* **`129040`** — AIS Class B Extended Position Report (расширенная позиция класса B)
* **`129041`** — AIS Aids to Navigation / AtoN (буи, маяки, навигационные знаки)
* **`129793`** — AIS UTC and Date Report (отчёты времени/даты)
* **`129794`** — AIS Class A Static & Voyage Data (название судна, позывной, тип, размеры, назначение)
* **`129809`** — AIS Class B Static Data Part A (название судна)
* **`129810`** — AIS Class B Static Data Part B (тип судна, позывной, размеры)

## ⚙️ Готовые строки `pgn_include` для скопирования

В настройках интеграции `nmea2000` в поле **Included PGNs** (`pgn_include`) вставьте одну из следующих строк (через запятую, без пробелов или с пробелами):

### Вариант А: Базовый (только приборы своей лодки, БЕЗ AIS)
Идеально для исключения создания любых сущностей чужих судов:
```text
60928,59904,126464,126996,127250,127258,127488,127489,127505,127506,127508,128259,128267,129025,129026,129029,130306,130310,130312
```

### Вариант Б: Полный (с поддержкой AIS-карты `ha/ais`)
Используется при работе с картой целей AIS:
```text
60928,59904,126464,126996,127250,127258,127488,127489,127505,127506,127508,128259,128267,129025,129026,129029,130306,130310,130312,129038,129039,129040,129041,129793,129794,129809,129810
```

## 📌 Инструкция по установке через UI Home Assistant

1. Откройте Home Assistant: **Настройки → Устройства и службы (Settings → Devices & Services)**.
2. Найдите интеграцию **NMEA 2000**.
3. Нажмите кнопку **Настроить (Configure)** на карточке интеграции.
4. В поле **Included PGNs** (`pgn_include`) вставьте нужную строку PGN из раздела выше.
5. Нажмите **Отправить (Submit)**.
6. Перезапустите Home Assistant для гарантированного применения фильтра.

## 🧹 Автоматическая очистка реестра от мусорных устройств

Для очистки накопленных фантомных устройств и устаревших `sensor.ais_*` из реестра Home Assistant используется скрипт `homeassistant/cleanup_nmea_devices.py`.

### Варианты запуска:

#### 1. Автоматическая зачистка с хоста через `deploy.sh`:
```bash
./deploy.sh --clean-ha
```
Скрипт подключается к контейнеру HA, удаляет мусорные/дублирующиеся NMEA-устройства и неиспользуемые сущности, после чего автоматически перезапускает Home Assistant.

#### 2. Запуск вручную внутри контейнера HA:
```bash
# Просмотр изменений без их применения (Dry Run)
docker exec homeassistant python3 /tmp/cleanup_nmea_devices.py --dry-run

# Очистка только накопившихся устаревших AIS-сущностей и фантомных устройств
docker exec homeassistant python3 /tmp/cleanup_nmea_devices.py --clean-ais

# Полная зачистка всех NMEA устройств и пересоздание реестра с нуля
docker exec homeassistant python3 /tmp/cleanup_nmea_devices.py --all
```

После выполнения очистки перезапустите Home Assistant:
```bash
docker restart homeassistant
```
